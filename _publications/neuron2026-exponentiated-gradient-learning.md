Abstract: Exponentiated gradient learning changes the magnitude of a synaptic weight while preserving its sign. In recurrent neural networks, this rule produced log-normal weight distributions and concentrated task-relevant computation in a small set of strong connections. The networks matched those trained with ordinary gradient descent on standard cognitive tasks, tolerated pruning better, and learned more effectively when only a few inputs were informative.
